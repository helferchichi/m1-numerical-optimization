# Numerical Optimization

M1 practicals, 2019–2020.

1. [Gradient methods and line search](tp1_gradient_methods.ipynb) compares fixed steps, Armijo and strong Wolfe conditions, Newton directions, and conjugate gradient.
2. [Constrained optimization](tp2_constrained_optimization.ipynb) fits a logistic classifier with BFGS and solves a ball-constrained quadratic using projection, penalties and multiplier updates.
3. [Sparse recovery and matrix completion](tp3_sparse_recovery.ipynb) uses proximal methods to estimate a sparse signal and fill missing entries in a low-rank matrix.

Run each notebook independently in Jupyter with Python, NumPy, SciPy and Matplotlib. The classification and recovery experiments use generated data.
